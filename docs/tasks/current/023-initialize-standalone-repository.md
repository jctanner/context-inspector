# Task: Initialize Standalone Repository

## Goal

Turn Context Inspector into a standalone Git repository and publish its initial
source history to `jctanner/context-inspector`.

## Acceptance criteria

- [ ] Runtime state, captures, credentials, dependencies, caches, and build
  output are excluded by `.gitignore`.
- [ ] The initial staged tree contains only intended project source and records.
- [ ] The repository uses the `main` branch.
- [ ] `origin` points to `git@github.com:jctanner/context-inspector.git`.
- [ ] The initial commit is pushed and tracks `origin/main`.
